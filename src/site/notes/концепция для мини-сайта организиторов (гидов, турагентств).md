#tourtoster 
# Идея
у каждого организатора (гида, турагентства) будет свой мини-сайт на поддомене к новому нашему домену tostertour.ru. Например alina.tostertour.ru \ westtour.tostertour.ru и т.п.
Организатор каким-либо образом скидывает туристу ссылку на свой мини-сайт, чтобы турист мог 
- ознакомиться с ассортиментом экскурсий, которые устраивает организатор
- просмотреть детали экскурсии (описание, что входит в стоимость и т.п.)
- забронировал экскурсию
- ввёл данные (ФИО, оплата)
- получил подтверждение бронирования

**Страуктура этого сайта**
- главная страница с "карточками" экскурсий  + фильтр по карточкам + блоком организатора "обо мне"
- страница отдельной экскурсии с описанием + виджет бронирования + страница подтверждения данных и оплаты + страница подтверждения бронирования
