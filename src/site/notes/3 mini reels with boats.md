# 1 видео

в начале используется ПЕРВАЯ маленькая лодка из уже сделанного большого ролика.

- **Маленькая лодка (0:00–0:05):**  
    **Text:** _"Lil bro doing his best..."_
    
- **Большая лодка (0:06–0:11):**  - вырезать из файла DJI_0527 с 2:31 и далее, может быть вид сзади когда лодка на ходу
    **Text:** _"BIG bro just flexed."_
    
- **Заключение  (0:12–0:17):**  - другой отрезок вырезать оттуда же, можно использовать тот же отрезок, что и das auto видео
    **Text:** **"Flex mode: activated🚤"**

# 2 видео

в начале используется ВТОРАЯ маленькая лодка из уже сделанного большого ролика.

- **Маленькая лодка (0:00–0:05):**  
    **Text:** _"Crew tender doing its job."_
    
- **Большая лодка (0:06–0:11):**  - аналогично первому
    **Text:** _"Owner's tender doing the most."_
    
- **Заключение  (0:12–0:17):**  - аналогично первому
    **Text:** **"Boss mode: ON + смайл с солнцезащитными очками"**
