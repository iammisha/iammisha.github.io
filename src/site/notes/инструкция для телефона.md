# ШАГ 4 — Установить удалённый доступ через RuStore

На телефоне Samsung Galaxy J6 (2018):

## 1. Установить RuStore

[иНСТРУКЦИИ](https://www.rustore.ru/instruction)

# ШАГ 5 — Настройки AnyDesk (КРИТИЧНО)

Открыть AnyDesk.

## Включить:

### 1. Unattended Access

(доступ без подтверждения)

Поставить постоянный пароль.



### 2. Accessibility Service

Если попросит:

Настройки → Спец. возможности → Installed Services → AnyDesk → ON

### 3. Draw over apps / Overlay

Разрешить.


### 4. Screen capture

Разрешить.


# ШАГ 6 — Отключить блокировку экрана

Настройки → Экран блокировки → Тип блокировки экрана

Выбрать:

Провести по экрану

или вообще без защиты, если отдельный телефон.

👉 НЕ ставить PIN/Pattern.


# ШАГ 7 — Увеличить таймаут экрана

Настройки → Дисплей → Тайм-аут экрана

Выбрать максимум 


# ШАГ 8 — Режим разработчика

## Включить:

Настройки → О телефоне → Сведения о ПО → 7 раз нажать "Номер сборки"

Появится “Параметры разработчика”.

---

## Там включить:

Stay awake

(не выключать экран при зарядке)

👉 ОЧЕНЬ важно


# ШАГ 9 — Отключить энергосбережение

Настройки → Обслуживание устройства → Батарея

Отключить:

- энергосбережение
- адаптивную батарею (если есть)


## Для AnyDesk отдельно:

Настройки → Приложения → AnyDesk → Батарея

Разрешить работу в фоне / без ограничений.
